# Portfólio para venda de sites

Base visual e funcional do portfólio Steinheuser Web, voltado à captação de clientes para desenvolvimento web.

A identidade usa a paleta extraída de `foto_perfil.png`: preto grafite, branco, ciano e azul elétrico.

## Visualizar

Abra `index.html` no navegador ou inicie um servidor local na pasta do projeto:

```powershell
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Personalizar primeiro

No `index.html`, substitua ou complete:

- nome pessoal e texto de apresentação;
- os links de LinkedIn, e-mail e WhatsApp;
- os textos, métricas ou novas imagens dos projetos D Confeito e Barbearia Monteiro;
- o texto da seção “Sobre”.

No `script.js`, atualize os textos e links dos estudos de caso exibidos ao clicar nos projetos.

O site foi feito em HTML, CSS e JavaScript puros, sem etapa de compilação ou dependências locais.
